# dot-field

The ambient dot field from the tol.is index, on its own.

A drifting dot field whose radius and alpha track a scalar wave. Three non-parallel waves with incommensurate wavelengths sum quasi-periodically over a warped lattice; the global wavelength breathes so the pattern never settles; a diagonal front crosses on a slow cycle, swelling the dots it passes. The pointer is a wave source: movement drops travelling ripples, a press drops a strong one, a resting cursor emits faint slow rings. Theme follows `prefers-color-scheme`.

Canvas 2D, no dependencies.

```sh
npm install
npm run dev
```

Live: https://dot-field-tolis.vercel.app
